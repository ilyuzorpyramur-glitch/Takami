## Где именно рвётся

Разбор ссылок сейчас берёт **один** кадр со страницы и на нём останавливается:

1. `collectAll()` ищет кадр через `doc.selectFirst(...)` — если на странице пять плееров и
   рабочий второй, он не будет найден вообще;
2. цикл по вложенности останавливается на первом же уровне, где что-то нашлось; глубже
   (плеер → страница плеера → ещё кадр) он не идёт;
3. `spec.video.hosters` (`HosterSpec` с `urlPattern` и `apiTemplate`) **не используется нигде**,
   кроме подписи в `SelfCheck` — то есть знание «это playerjs, карту надо спросить отдельно»
   в спеке есть, а в разборе его нет;
4. в разметке плееров адрес бывает в `data-iframe`, `data-player`, `data-href`, в объекте
   `file:` внутри JS, в base64, с экранированием `\/` и `\u0026`, относительным путём;
   `normalizeMedia()` понимает только `//` и готовый `http(s)`;
5. `video/*` не умеет главного: разобрать **страницу плеера** (playerjs-скрипт) и достать оттуда
   карту файлов.

Пока это не исправлено, таблицы качества и озвучек этапа 7 остаются пустыми на всех сайтах,
а экран честно пишет «не определена» — это не баг этапа 7, а отсутствующий уровень.

## Что должно получиться

Из страницы серии приложение доходит до **прямого адреса файла** (mp4 / webm / m3u8) по цепи
«страница серии → все плееры на ней → страница плеера → карта файлов или HLS-мастер», и делает
это **по спеке**, а не кодом под конкретный сайт. Если плеер закрылся, отдал капчу или пустую
страницу — источник честно сообщает, что ссылки нет; выдуманных адресов и подставленного
качества быть не может.

Всё, что отличается от сайта к сайту (шаблон адреса плеера, шаблон запроса карты, атрибуты
встраивания, максимальная глубина), — поля `SiteSpec`, а не ветки в коде.

## Шаг 1. Декодер плеера

Новый файл `takami/video/Playerjs.kt` — чистая функция, без сети:

```kotlin
object Playerjs {
    /** Ссылки из страницы плеера: карта файлов, плейлист, одиночный адрес. */
    fun parse(html: String, dubbing: String = ""): List<QualityLink>
}
```

Поддержать, в этом порядке приоритета:

1. **Плейлист playerjs**: `file:"[{""title"":""360p"",""file"":""//host/a.mp4""}, …]"` —
   элементы массива объектов, качество из `title`, адрес из `file`;
2. **строковая карта**: `file:"[360p]//host/a.mp4,[720p]//host/b.mp4"` — отдать в `PlayerMap`;
3. **объектная карта**: `file:{"360":"//host/a.mp4","720":"//host/b.mp4"}` — отдать в
   `PlayerMap`;
4. **массив адресов**: `file:["//host/a.mp4","//host/b.m3u8"]` — без метки качества;
5. **одиночный адрес**: `file:"//host/index.m3u8"` — без метки;
6. **base64**: значение `file` без `/`, `:` и `http`, длиной ≥ 24 — раскодировать **один раз**
   и разобрать результат пунктами 1–5. Битый base64 — пустой список, без исключения.

Требования: ключ `file` ищется в одинарных и двойных кавычках, с пробелами и без; адреса
проходят через `MediaUrl` (шаг 4); мусор и пустое поле дают пустой список; порядок ссылок
сохраняется; дедуп — по адресу.

## Шаг 2. Плеер по спеке

Новый файл `takami/video/Hoster.kt`:

```kotlin
object Hoster {
    /** Какой из описанных в спеке плееров это; null — не описан. */
    fun match(spec: SiteSpec, url: String): HosterSpec?

    /** Адрес запроса карты: подстановка {id} в apiTemplate; null — карту не спрашиваем. */
    fun apiUrl(hoster: HosterSpec, pageUrl: String): String?

    /** Идентификатор плеера из адреса или из разметки; пусто — не нашли. */
    fun idOf(hoster: HosterSpec, url: String): String
}
```

- `match` — по `urlPattern` (`Regex`, регистронезависимо), первый подошедший;
- `idOf` — по `idRegex` из спеки, если задан, иначе по `urlPattern` (первая группа);
- `apiUrl` — `apiTemplate` с `{id}`; если `{id}` нет, `apiTemplate` берётся как есть;
  пустой `apiTemplate` → `null`, и `Playerjs` применяется к самой странице плеера;
- `kind`: `playerjs` → страницу (или ответ `apiUrl`) отдать в `Playerjs.parse`;
  `hls` → адрес сам является ссылкой, добавить как есть; `iframe` → идти вглубь.

В `HosterSpec` добавить одно поле с дефолтом: `idRegex: String? = null`. Больше `HosterSpec`
не менять.

## Шаг 3. Обход цепочки

Переписать путь ссылок в `SpecEngine` — по шагам:

1. **Собрать всех кандидатов** со страницы серии (и из блока каждой озвучки): `iframe[src]`,
   `iframe[data-src]`, `[data-iframe]`, `[data-player]`, `[data-href]`, `a[href]` и `a[data-href]`,
   `video[src]`, `source[src]`, `object[data]`. Атрибуты встраивания — из
   `spec.video.embedAttrs` (новое поле, дефолт: `src, data-src, data-iframe, data-player,
   data-href, data`).
2. **Отфильтровать и обрезать**: убрать `about:blank`, `javascript:`, пустое и повторяющееся;
   предел — `spec.video.maxPlayers` (новое поле, дефолт `8`).
3. **Обойти каждого** в ширину: узел → `Hoster.match` → (при `apiTemplate` — запрос карты) →
   `Playerjs.parse` → найденные ссылки; если ссылок нет — следующий кадр внутри узла, но не
   глубже `spec.video.iframeDepth`.
4. **Не останавливаться на первом успехе**: собрать со всех кандидатов, затем `Quality.dedupe`
   и `Quality.arrange`. Первый рабочий плеер — только для подписи в `SelfCheck`.
5. **Потолок запросов**: `spec.video.maxRequests` (новое поле, дефолт `12`) на одну серию.
   Исчерпали — возвращаем то, что собрали; не падаем и не висим.
6. Каждый запрос — через `Fetcher` с `referer` той страницы, из которой пришли. Редирект
   вида `location.href = "..."` — один переход, не больше.

`videos()` и `streams()` сохраняют текущую сигнатуру: их вызывает `TakamiForge`, который ты
не правишь.

## Шаг 4. Адреса

Новый файл `takami/video/MediaUrl.kt` — вся нормализация в одном месте, чистая функция:

```kotlin
object MediaUrl {
    /** Приводит адрес из разметки к абсолютному; пусто — адрес непригоден. */
    fun normalize(raw: String, baseUrl: String? = null): String
}
```

Обязательные случаи: `\/` → `/`, `\u0026` → `&`, `&amp;`/`&#38;` → `&`, снятие обрамляющих
кавычек, запятых и пробелов, `//host/…` → `https://host/…`, `%2F`-кодирование раскодировать
**один раз**, если результат начинается с `http`; относительный путь (`/embed/123`) — к
`baseUrl`, если он есть, иначе пусто; `about:blank`, `javascript:`, `data:` → пусто.
`normalizeMedia()` в `SpecEngine` заменяется вызовом `MediaUrl.normalize` — вторая копия
логики не нужна.
