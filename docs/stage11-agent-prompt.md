## Твои границы

Ты работаешь **только с кодом**: реализация, гейт, тесты, протокол, инструмент отчёта.

- не подгоняй шаблоны под конкретный сайт — только под то, что код может доказать сам;

## Что должно получиться

Ссылка на видео добывается в трёх случаях, где сейчас пусто:

1. адрес собирается в JS, но конфиг плеера лежит в странице как данные;
2. плеер создаётся скриптом, кадр не в разметке;
3. адрес появляется только после запроса к API плеера.

И по-прежнему честно **не** добывается там, где ссылки нет вовсе: DRM, ограничение по
лицензии, обязательный вход. Это не провал реализации, это правильный ответ — в отчёте и в
проверке он должен выглядеть отказом с причиной, а не нулём без объяснения.

Главное требование: найденная ссылка должна **играть**. Значит, заголовки окна
(`Referer`, `Origin`, `User-Agent`, `Cookie`) идут вместе со ссылкой до `Video.headers`.

## Три слоя, строго по порядку

| # | Слой | Стоимость | Когда работает |
|---|---|---|---|
| 1 | статика (`Chain.collect`) | 1–3 запроса, без исполнения чужого кода | всегда первым |
| 2 | шахта конфига (`video/config/`) | 1–2 запроса, чистый разбор текста | если слой 1 пуст |
| 3 | снимок сети (`video/sniff/`) | до 12 с, реальный `WebView` | если пусты 1 и 2 |

Слой 3 дорогой: он не должен включаться, если ссылка уже есть. И он не должен включаться
на домене, которому мы запретили вмешательство.

2. **`SPEC_VERSION` остаётся `3`**. Новые поля спеки — только аддитивные и только с
   дефолтами, чтобы спеки версии 3 читались байт в байт как раньше.
   `SpecVersion.kt`, `SpecMigration.kt`, `SpecHistory.kt`, `SpecRollback.kt` не трогать.
3. `kodikdreamcast` (dreamerscast.com) — только чтение: ни снимка, ни шахты, ни правки спеки.
   Пропуск оформляется кодом и тестом (`SniffPolicy`), а не комментарием.
4. `heal/**` не трогать: лечение источника — этап 10, оно принято. Снимок не вызывается

5. Никаких ключей, токенов, cookies в коде, логах, спеках, коммитах, отчётах. Токена Kodik

6. Вся обычная сеть — через `Fetcher`. `OkHttpClient` наружу не выставлять, `Jsoup.connect`

   родной плеер сайта, мы лишь читаем его запросы. Свой HTTP-клиент внутри снимка запрещён.
7. Обходов нет: капча не решается автоматически (только вкладка для человека), DRM не
   взламывается (Widevine/ClearKey — честный отказ `drm`), Cloudflare не пробивается.
   403/капча — стоп по домену, как сейчас.
8. Снимок не работает в фоне: только по действию пользователя (открытие серии, шаг проверки,
   прогон). Один `WebView` одновременно на всё приложение. Окно снимается в `finally` при
   любом исходе, включая отмену корутины.
9. Тесты и гейт **без сети и без `WebView`**: снимок проверяется на подставных данных
   (`SniffInput`), шахта — на коротких фикстурах, написанных руками, без названий тайтлов и
   выдержек из живых страниц.
10. Ktlint: `indent_size = 4`, `max_line_length = 120`. Комментарии по-русски, без `TODO`.
    Тексты интерфейса — русские, без англицизмов.
11. Отчёт, журнал и телеметрия без приватного: только домен, шаг, слой, числа и секунды.
    Ни названий тайтлов, ни путей, ни query-строк, ни текста страниц, ни cookies, ни ID.

## Шаг 1. Заголовки не теряются (делать первым)

Сейчас `SpecEngine.videos()` собирает `Video(stream.url, quality, url)` — три устаревших
аргумента, заголовков нет. Из-за этого даже найденная ссылка может не играть.

- `QualityLink` и `VideoStream` получают `headers: Map<String, String> = emptyMap()`
  (аддитивно, с дефолтом; `VideoStream.of` переносит их).
- `SpecEngine.videos()` передаёт заголовки в `Video` через `okhttp3.Headers`
  (`Headers.headersOf(...)`), а не через устаревший конструктор без заголовков.
- Дедуп по-прежнему по адресу; при совпадении адресов остаются **непустые** заголовки
  первого, у которого они есть.
- Тест: ссылка с заголовками доезжает до `Video.headers`; ссылка без них даёт `null`,
  а не пустую карту.

Этот шаг не зависит от остальных и должен быть отдельным коммитом.

## Шаг 2. Шахта конфига — `video/config/`, чистый разбор

Никакой сети: на вход текст страницы, на выход `List<QualityLink>`.

```kotlin
/** Что нашли в данных страницы. */
data class MinedLink(val url: String, val quality: String = "", val kind: String = "")

object MediaMiner {
    /** Ищет адреса в данных страницы: JSON, атрибуты, скрипты. */
    fun mine(html: String, pageUrl: String, spec: VideoSpec): List<MinedLink>
}
```

Правила:

- ключи, по которым ищем: `file`, `file:`, `src`, `sources`, `source`, `playlist`, `manifest`,
  `hls`, `m3u8`, `mp4`, `dash`, `mpd` — сравнение по имени ключа, не по всему тексту;
- снятие кодировок **однократное**, чтобы не разъесть настоящие адреса: `\u002F`, `\/`,
  `&amp;`, `&#38;`, `%2F`, `%3A`, `%3D`, `base64`;
- `base64` пробуем только для значений, которые целиком похожи на base64 и дают после
  раскодирования `http`;
- `m3u8`, у которого в теле мастер-плейлист, разбирает уже существующий `HlsMaster` — не
  дублировать;
- плейлист из многих ссылок (встречается до нескольких сотен) отбирается по номеру серии:
  если совпадения нет — **ничего не отдаём**, а не «первую попавшуюся»;
- результат — только http(s), без `blob:` и `data:`, без дублей.

Тесты: JSON-конфиг в одном порядке и в другом, экранированный адрес, base64, плейлист с
отбором по серии и без совпадения, мусор в разметке (ключ есть, адреса нет).

## Шаг 3. Снимок сети — `video/sniff/`, настоящий `WebView`

Задача: открыть страницу серии так, как её открыл бы человек, и записать, какие медиа-адреса
плеер запросил сам. Ничего не подменяем и не переписываем: `shouldInterceptRequest`
возвращает `null`, запрос идёт как есть.

Два канала, оба обязательны:

1. `WebViewClient.shouldInterceptRequest(view, request)` — каждый http(s)-запрос окна,
   включая вложенные кадры и `fetch`/XHR.
2. Зацепка на JS, ставится **до** скриптов страницы (`onPageStarted` +
   `evaluateJavascript`): `XMLHttpRequest.prototype.open`, `window.fetch`,
   сеттеры `HTMLMediaElement.prototype.src` и `HTMLSourceElement.prototype.src`,
   `playerjs.file`, если он есть. Нужна для `blob:` и для адресов, которые до сети не доходят.

Обратный вызов из JS — через `addJavascriptInterface` с одним методом, принимающим строку;
внутри строгая проверка: только `http`/`https`, длина ≤ 2 048, никакой рефлексии и никаких
вызовов из JS в Kotlin, кроме этого метода.

```kotlin
/** Что просили у снимка. */
data class SniffRequest(
    val url: String,
    val referer: String = "",
    val timeoutMs: Int = 12_000,
    val settleMs: Int = 1_500,
    val maxPages: Int = 2,
)

/** Что снимок принёс. */
data class SniffHit(val url: String, val contentType: String = "", val from: String = "")

data class SniffResult(
    val hits: List<SniffHit> = emptyList(),
    val stopReason: String = "",   // found, timeout, blocked, drm, unavailable
)
```

Правила снимка:

- ожидание: до `timeoutMs` первого медиа-адреса, затем ещё `settleMs` «дозор», чтобы поймать
  мастер, а не только первый сегмент;
- не больше `maxPages` загруженных страниц и один `WebView` на всё приложение (мьютекс);
- cookie берутся у приложения (`CookieManager`), чтобы вход сохранялся; свои cookie не
  выдумываем и в файлы не пишем;
- если страница сама сообщает «недоступно по лицензии» — `stopReason = unavailable`,
  ссылок не ждём и не досматриваем таймаут;
- если плеер отдаёт `blob:` без сети и без перехвата — `stopReason = drm`;
- отмена корутины, таймаут, исключение — окно снимается в `finally`, `stopReason` заполнен;
- в фон не уходим: `WebView` создаётся только при видимом экране; проверка «нет вызова из
  `init`/`Application`/таймеров» — часть гейта.

Тесты (без `WebView`): подставной вход с готовым набором запросов — проверяется отбор,
ранг, дедуп, поведение по таймауту и по отмене, заполнение `stopReason`.

## Шаг 4. Что оставляем из пойманного

`sniff/MediaFilter.kt`, чистая функция:

- берём: `.m3u8`, `.mpd`, `.mp4`, `.webm` — по адресу **и** по `Content-Type`
  (`application/vnd.apple.mpegurl`, `application/dash+xml`, `video/mp4`, `video/webm`);
- выбрасываем: `.ts`, `.m4s`, `blob:`, `data:`, картинки, шрифты, рекламу и аналитику;
- ранг: мастер `m3u8` (в теле `#EXT-X-STREAM-INF`) → `mp4` → медиа `m3u8`;
- дедуп по полному адресу; query **не режем** — в нём часто подпись, без неё ссылка мертва;
- `denyHosts` из спеки — стоп-лист; пустой список ничего не запрещает.

Тесты: каждый тип по адресу, каждый тип по `Content-Type`, ранг, дедуп, `denyHosts`,
сегменты не попадают в результат.

## Шаг 5. Поля спеки — только аддитивные

```kotlin
/** Как добывать ссылку, если статики не хватило. */
data class SniffSpec(
    val mode: String = "fallback",   // fallback | always | never
    val timeoutMs: Int = 12_000,
    val settleMs: Int = 1_500,
    val maxPages: Int = 2,
    val mediaPatterns: List<String> = listOf(".m3u8", ".mpd", ".mp4", ".webm"),
    val denyHosts: List<String> = emptyList(),
    val passHeaders: List<String> = listOf("Referer", "Origin", "Cookie", "User-Agent"),
)
```

`VideoSpec` получает `sniff: SniffSpec = SniffSpec()`. Всё с дефолтами: спека без поля
читается как `fallback`. Значение вне перечисления трактуется как `fallback`, а не падает.

Тест: спека версии 3 без `sniff` даёт ровно `fallback`; сериализация старой спеки не меняется
(лишнее поле не появляется в JSON).

## Шаг 6. Порядок слоёв и память домена

`SpecEngine.linkReport()`:

1. статика (`Chain.collect`) — как сейчас;
2. если пусто и `mode != "never"` — шахта (`MediaMiner`) по уже загруженной странице, без
   нового запроса;
3. если пусто и `mode != "never"` — снимок (`MediaSniffer`);
4. `expandMaster` и фильтр по озвучке — как сейчас, поверх объединённого результата.

`sniff/SniffMemo.kt` — маленькая память в `filesDir` (`sniff-memo.jsonl`), чтобы не платить
12 секунд за каждую серию:

- строки: домен, слой, который сработал (`config`, `sniff`), дата, число успехов и провалов;
- **адреса и query не хранятся** — только домен и слой;
- если снимок вчера сработал — сегодня начинаем с него, но не на `mode = "never"`;
- две неудачи подряд — слой не пробуем 24 часа, дальше снова;
- файл обрезается до 200 строк, битые строки пропускаются;
- удаляется одной кнопкой в интерфейсе прогона и одним коммитом (как телеметрия).

Тесты: порядок слоёв на подставных данных, `never` не вызывает снимок, память уважает
`never` и срок, битая строка не ломает чтение.

## Шаг 7. Отказ вместо нуля

`sniff/SniffVerdict.kt` — из `SniffResult` и найденных ссылок делает честный итог:

| ситуация | итог для проверки |
|---|---|
| ссылка есть и отдаёт поток | `ok` |
| ссылка есть, поток не отдаётся | `no_video` (как сейчас) |
| страница сказала «недоступно по лицензии» | `unavailable` |
| плеер только `blob:`/DRM | `drm` |
| таймаут или 403/капча | `blocked` |
| ничего из перечисленного не нашли | `no_links` |

Эти причины идут в `ParseFailures.noteFailure(spec.host, "video", <тип>, spec.version)` —
тип короткий, без текста страницы. Ключ шага остаётся `video`: новых шагов не заводить.

`SniffPolicy.canSniff(spec, host)`:

- `false` для `dreamerscast.com` и `kodikdreamcast`;
- `false` при `mode = "never"`;
- `false`, если в спеке нет ни одной серии (нечего снимать);
- `false`, если домен в брейкере (`HostGuard`), — не долбить упавший сайт.
