# Приёмник отчётов Takami

Cloudflare Worker: принимает короткие обезличенные отчёты о сбоях источников.
Своего сервера нет — адрес не выдаёт машину, за которой стояла бы база.

## Что делает

- принимает только POST с JSON-телом до 64 КБ;
- проверяет схему: неизвестные поля отбрасываются, неверные типы дают 400;
- без общего секрета отвечает 401;
- складывает события в KV;
- удаляет записи старше `RETENTION_DAYS` дней (по умолчанию 90): и по сроку
  жизни ключа, и ежедневной чисткой по расписанию.

## Развёртывание

1. Создать namespace KV:
   `npx wrangler kv namespace create REPORTS`
2. Подставить выданный id в `wrangler.toml` вместо `REPLACE_WITH_KV_NAMESPACE_ID`.
3. Задать общий секрет, с которым подписывается приложение:
   `npx wrangler secret put TELEMETRY_TOKEN`
4. При необходимости поменять срок хранения в `[vars]` (`RETENTION_DAYS`).
5. Выложить: `npx wrangler deploy`.
6. Полученный адрес положить в GitHub-секрет `TELEMETRY_URL` — оттуда он
   попадает в сборку. В репозитории адреса нет.

## Переменные

| Имя | Где задаётся | Назначение |
|---|---|---|
| `REPORTS` | `wrangler.toml`, привязка KV | хранилище событий |
| `TELEMETRY_TOKEN` | `wrangler secret put` | общий секрет для 401 |
| `RETENTION_DAYS` | `[vars]` | срок хранения, дней |

## Проверка

```
curl -X POST "$(ваш адрес)" -H "Authorization: Bearer <секрет>" \
  -H "content-type: application/json" \
  -d '{"events":[{"host":"example.com","step":"catalog","error":"network"}]}'
```

Без заголовка авторизации ответ будет 401 — это ожидаемо.
