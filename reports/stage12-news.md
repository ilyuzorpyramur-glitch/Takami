# Этап 12 — новости аниме-сайтов на главной (v1)

## Что сделано

- **Спека.** В `SiteSpec` два поля с дефолтами: `news: NewsSpec? = null` и
  `newsCheckedAt: Long = 0L`; `NewsSpec` — в пакете `takami/news`. Старые спеки
  читаются без миграции, `SPEC_VERSION` остался 3, миграций БД нет.
- **Разбор** (`NewsParser.kt`): RSS 2.0 и Atom, раздел по `NewsSpec`, анонс без
  тегов, обрезанный по словам; дедуп по адресу, затем по нормализованному
  заголовку; сортировка по дате, без даты — в конец.
- **Детект** (`NewsDetector.kt`): ссылка-подсказка, страница раздела одним
  запросом через общий `Fetcher`; не меньше трёх однотипных карточек с разными
  адресами, иначе `null`. Заглушка, 404, пустота — «новостей нет», не ошибка.
  В `Forge.build` — один дополнительный запрос, только если ссылка найдена.
- **Правила** (`NewsPolicy.kt`): `dreamerscast.com`/`kodikdreamcast` закрыты
  кодом и тестом; не больше двух источников за открытие; повтор не раньше
  недели; TTL кэша 45 минут; мёртвая лента молчит неделю; список лент пуст,
  пока адреса не проверены оператором.
- **Кэш и лента** (`NewsCache.kt`, `NewsFeed.kt`): файл на источник
  `files/news/<sourceId>.json`; сеть упала — прошлый снимок; пустой ответ кэш
  не затирает; не больше десяти записей. Полного текста нет ни в модели, ни в кэше.
- **Интерфейс**: блок `item(key = "home_news")` после «Историй», до «Для вас»;
  экран «Все новости», кнопка «Обновить» — единственный интерактивный запрос;
  пусто — «Новостей пока нет» и «Проверить снова». Тап — браузер. Строки
  `news_*` в `base` и `ru`, в Compose-коде литералов нет.
