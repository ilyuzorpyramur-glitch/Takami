# Этап 12 — новости аниме-сайтов на главной (v1)

## Что сделано

- **Спека.** В `SiteSpec` два аддитивных поля с дефолтами: `news: NewsSpec? = null`
  и `newsCheckedAt: Long = 0L`; `NewsSpec` живёт в пакете `takami/news`. Старые
  спеки читаются без миграции, `SPEC_VERSION` остался 3, файлы версии и истории
  не тронуты, миграций БД нет — новости не касаются схемы библиотеки.
- **Разбор** (`takami/news/NewsParser.kt`): RSS 2.0 и Atom из фикстур, раздел по
  `NewsSpec`, анонс без тегов, обрезанный по словам, дата из RFC-822/ISO, кривая
  дата — null. Дедуп по адресу, затем по `normalizeDiscoveryTitle`; сортировка
  по дате, без даты — в конец.
- **Детект** (`NewsDetector.kt`): ссылка-подсказка на загруженной странице,
  страница раздела добирается одним запросом через общий `Fetcher`; не меньше
  трёх однотипных карточек с разными адресами, иначе `null`. Заглушки, 404,
  пустота — «новостей нет», не ошибка. В `Forge.build` — один дополнительный
  запрос, только если ссылка реально найдена.
- **Правила** (`NewsPolicy.kt`): `dreamerscast.com`/`kodikdreamcast` закрыты кодом
  и тестом; не больше двух источников за открытие главной; повтор не раньше
  недели; TTL кэша 45 минут; мёртвая лента молчит неделю; список лент пуст,
  пока адреса не проверены оператором — выдуманных адресов в коде нет.
- **Кэш и лента** (`NewsCache.kt`, `NewsFeed.kt`): файл на источник
  `files/news/<sourceId>.json`; сеть упала — прошлый снимок; пустой ответ кэш
  не затирает; не больше десяти записей с источника. Полного текста нет ни в
  модели, ни в кэше.
- **Интерфейс**: блок `item(key = "home_news")` после «Историй», до «Для вас» —
  заголовок, «Все», пять карточек (заголовок, анонс, источник, дата); экран
  «Все новости» — плоский список, кнопка «Обновить» (единственный
  `INTERACTIVE`-запрос), пусто — «Новостей пока нет» и «Проверить снова».
  Тап открывает запись в браузере. Пустой список не рисует блок и не показывает
  ошибку на главной. Строки `news_*` в `base` и `ru`, в Compose-коде литералов нет.

## Чем доказано

- Гейт: `bash .github/scripts/verify-stage12.sh` — 0 FAIL, внутри регрессии
  этапов 11 и 10 с разрешённой правкой общих файлов.
- Тесты без сети (`app/src/test/java/eu/kanade/takami/news/`): разбор лент и
  раздела, детект с подменной сетью, кэш, правила, совместимость старого JSON.
- CI ветки `feature/news-feed`: тесты и сборка зелёные (id прогонов — в отчёте
  сдачи).

## Что осталось

- Ручная кнопка «Проверить новости» в настройках источника не сделана: экран
  настроек принадлежит прошлым этапам; интерактивная проверка доступна кнопкой
  «Проверить снова» на экране новостей.
- Список RSS-лент пуст: адреса добавятся после проверки оператором, механизм
  и пометка мёртвых лент готовы.
- Картинки, чтение внутри приложения, уведомления — вне рамок v1.
