# Ранобэ-генератор

Генератор источников ранобэ на устройстве: по одной ссылке собирается
спека сайта и превращается в обычный источник приложения.

## Слои

- `NovelForge` — порядок сборки: что отдал сайт, карточки, главы, текст.
- `NovelAutoDetect` — селекторы по структуре: повтор карточки со ссылкой
  и картинкой, ссылки с номером главы, блок с наибольшим числом абзацев.
- `NovelMarkup` — различает серверную разметку, каркас SPA и защиту.
- `NovelCheck` — причина отказа вместо нуля: `no_catalog`, `no_chapters`,
  `no_text`, `js_only`, `anti_bot`, `blocked`.
- `NovelEngine` — чистые `parse*` над готовым HTML плюс сеть через `Fetcher`.
- `NovelStore` — один файл `.novel.json` на домен в filesDir.
- `NovelSourceId` — постоянный номер из хеша домена, диапазон 7.2e12.

## В приложении

`VirtualNovelSource` реализует `NovelCatalogueSource`: каталог, лента,
поиск, карточка, главы и текст главы. `NovelForgeSources` регистрирует
источники в `AndroidNovelSourceManager` рядом с плагинами; мастер
`NovelForgeScreen` открывается из списка расширений ранобэ.

Текст главы отдаётся HTML абзацев: служебные блоки выбрасываются до
чтения, короткие обрывки отсеиваются порогом `minParagraph`, длина
ограничена `maxChars`.
