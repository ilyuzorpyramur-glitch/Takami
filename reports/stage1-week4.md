# Неделя 4: версии спеки, история и откат

Ветка: `stage4/spec-versions`. Гейты: 28 из 28 (плюс регрессия этапа 3), 0 провалов.

## Что теперь умеет приложение

**Неудачная правка источника откатывается сама.** После сборки источник проходит проверки:
каталог, вторая страница, карточка, серии, видео. Число пройденных проверок сохраняется
вместе со спекой. Если после правки их стало меньше, приложение возвращает предыдущую
рабочую версию, а в журнал пишет причину — какие именно проверки упали. Пользователь ничего
не замечает: источник просто продолжает работать как раньше.

**История трёх версий.** На каждый источник хранятся текущая и две прошлых рабочих версии.
Версия хранится целиком, поэтому откат возвращает всё: выбранную иконку, отмеченные озвучки,
настройку качества, ленты каталога и новинок. Самые старые записи вытесняются — файл не растёт
бесконечно. История переживает перезапуск приложения.

**Старые установки читаются.** Файл, записанный до появления версий, читается целиком: ни один
источник не теряется, все поля остаются на месте. После первого чтения файл помечается текущей
версией схемы, и повторная миграция уже ничего не меняет. Файл с незнакомыми полями — например,
записанный более новой сборкой — тоже читается без падения: лишние поля игнорируются.

**Список источников не теряется при сбое.** Запись идёт через временный файл с последующим
переименованием: если приложение закрыть посреди сохранения, прежний список останется целым.
Битый файл истории читается как пустая история — источник продолжает работать.

## Как это проверено

Тесты на реальных файлах во временном каталоге, без сети и без ожиданий:

- файл без поля версии читается со всеми полями;
- файл с лишним полем читается без падения;
- повторная миграция ничего не меняет;
- после четырёх сохранений в истории ровно три версии;
- откат возвращает иконку, озвучки и качество целиком и переживает перезапуск;
- меньше проверок после правки — откат, причина записана в журнал;
- столько же или больше проверок — новая версия остаётся;
- битый файл истории — пустая история, мусор вместо файла спек — пустой список.

## Ограничения

Новых зависимостей и разрешений нет: всё на том, что уже есть в проекте. Спеки по-прежнему
лежат только на устройстве и никуда не отправляются.
