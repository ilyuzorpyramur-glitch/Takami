# Этап 10 — самолечение спеки

## Что добавлено

- **План** (`heal/HealPlanner.kt`): по провалившимся шагам — одна часть:
  каталог, карточка, серии, пагинация. Видео не лечится (ось этапа 9).
- **Правила** (`heal/HealPolicy.kt`): только для чтения (`dreamerscast.com`,
  `kodikdreamcast`), видео, источник без истории и проверок, лимит попыток,
  паузы 6/24 часа, требование зафиксированной поломки.
- **Правка** (`heal/HealMerge.kt`): меняется только выбранная секция; имя,
  язык, адрес, иконки, фильтры, видео, озвучки, поиск, версия, счёт проверок
  не трогаются; пустая секция — спека без изменений; идемпотентно.
- **Вердикт** (`heal/HealVerdict.kt`): принять, только если леченый шаг
  починился и никто другой не стал хуже; равный счёт при сломанном шаге —
  отказ, правка не сохраняется.
- **Оркестрация** (`heal/Healer.kt`): проверка → план → правило → сборка через
  общий `Forge` → слияние → повторная проверка → вердикт → сохранение или
  отказ. Триггеры — `user` и `sweep`. 403/капча дают `blocked`, домен
  остывает сутки. Исключение не выходит наружу.
- **Журнал** (`heal/HealLog.kt`): `heal.jsonl`, строка на попытку: домен,
  часть, попытка, решение, причина, шаги, триггер, время. До 500 строк, битые
  строки пропускаются, `state(host, now)` — состояние для правила.
  `SpecJournalEntry` дополнен полями `part`, `attempt`, `decision` с дефолтами.
- **Экран** (`ui/takami/HealScreen.kt`): что сломалось, «Можно починить» /
  «Починка недоступна» / «Подождите N ч», кнопка «Починить», итог, журнал.
  Вход — «Починить источник» в меню расширений.
- **Прогон** (`takami/Sweep.kt`): отметка `healed` в итоге — лечение в прогоне
  по общим правилам. В меню возвращён пункт «Прогон сайтов».
- **Точки входа**: `TakamiForge.heal(host, trigger)` — явный вызов, из `init`
  лечение не стартует; событие лечения идёт через приёмник провалов, шаг
  `heal`; у `ForgeResult.Failure` есть пометка `blocked`.

Видео исключено: ось целиком у этапа 9; в журнале остаётся `video_owned`.

Пороги: 2 попытки в сутки; пауза 6 часов после провала, 24 часа после двух
подряд и после защиты сайта; приём — только починка леченого шага без
деградации соседей, строже общего счёта проверок.
